# Mario Bros Landing Page

Projeto de landing page desenvolvido para praticar estruturação de páginas com HTML e estilização com CSS.

## Tecnologias utilizadas

- HTML
- CSS

## Objetivo

O objetivo deste projeto foi praticar conceitos de desenvolvimento frontend, organização visual e criação de interfaces para web.

## Aprendizados

Durante o desenvolvimento, trabalhei principalmente com:

- Estruturação de conteúdo com HTML
- Estilização com CSS
- Organização de layout
- Construção de uma página visual para web
